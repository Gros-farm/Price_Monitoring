# Gros.farm Price Monitor

Стартовая интерактивная болванка для сервиса мониторинга цен по одному выбранному магазину.

## Что уже есть

- выбор периода;
- выбор торговой сети;
- категории: `Фрукты`, `Овощи`, `Ягоды`, `Зелень`, `Грибы`;
- поиск по ассортименту выбранной сети;
- таблица товаров с текущими ценами;
- выбор нескольких товаров;
- SVG-график динамики цен по выбранным товарам.

## Как запустить сайт локально

Из папки проекта:

```bash
node server.js
```

Потом открыть:

```text
http://127.0.0.1:4173/
```

Сервер отдает статический интерфейс и локальные API для чтения последнего успешного кеша данных.

## Как выложить сайт

Для публичного доступа лучше использовать web service, а не GitHub Pages: сервер отдает интерфейс и JSON-данные из папки `data/`.

Самый простой вариант без покупки домена — Render или Railway. Оба дадут бесплатный технический адрес вида `*.onrender.com` или `*.up.railway.app`.

### Render

1. Отправьте актуальную версию проекта в GitHub:

```bash
git add .
git commit -m "Prepare server deployment"
git push origin main
```

2. В Render создайте **New → Web Service**.
3. Подключите репозиторий `Gros-farm/Price_Monitoring`.
4. В настройках сервиса выберите:

```text
Runtime: Docker
Branch: main
Health Check Path: /health
```

5. Если Render не подтянет `render.yaml` автоматически, добавьте переменные:

```text
HOST=0.0.0.0
DATA_DIR=/app/data
```

6. Нажмите **Deploy Web Service**.

После деплоя сайт будет доступен по адресу Render, например:

```text
https://grosfarm-price-monitor.onrender.com/
```

### Railway

1. Создайте новый Railway project из GitHub-репозитория.
2. Railway найдет `Dockerfile` и соберет контейнер.
3. В **Variables** можно добавить:

```text
HOST=0.0.0.0
```

4. В **Networking** включите публичный домен.

Адрес будет вида:

```text
https://price-monitoring-production.up.railway.app/
```

## Как обновляются данные Ашана

Интерфейс не парсит сайт Ашана напрямую из браузера и сервер Render тоже не ходит на сайт магазина по клику. Это сделано специально: сайты сетей часто блокируют дата-центры и длинные HTTP-запросы.

Сайт читает последний успешный кеш:

```text
data/auchan-products.json
```

Кнопка **Обновить** теперь только подтягивает последний сохраненный каталог и статус агента. Новый сбор запускается отдельным агентом:

```bash
npm run agent:auchan
```

Для Ашана агент использует видимый браузер Camoufox (`--headed`), потому что прямой HTTP-запрос получает QRator-челлендж, а headless-браузер может падать в локальном окружении macOS. Если `npm` недоступен, можно запустить тот же агент напрямую:

```bash
/private/tmp/price-monitor-venv/bin/python scripts/agents/run.py --store auchan
```

Агент описан в:

```text
scripts/agents/stores.json
scripts/agents/run.py
```

Для всех магазинов сразу:

```bash
npm run agent:all
```

После успешного запуска агент обновит `data/auchan-products.json` и запишет статус в:

```text
data/agent-status.json
```

Если сайт магазина блокирует сборщик, старый кеш не перезаписывается, а интерфейс продолжает работать с последними сохраненными данными.

### Как добавить следующий магазин

1. Создать сборщик, который пишет JSON в формате:

```json
{
  "storeId": "perekrestok",
  "source": "perekrestok.ru",
  "updatedAt": "2026-05-21T12:00:00+00:00",
  "notice": "Перекресток: загружено 120 позиций.",
  "products": []
}
```

2. Добавить магазин в `scripts/agents/stores.json`.
3. Добавить кнопку/логотип магазина в `app.js`.
4. Запускать `npm run agent:all` или отдельную команду магазина.

### Низкоуровневый запуск Ашана

Агент внутри вызывает существующий сборщик:

```bash
python3 scripts/fetch_auchan.py --output data/auchan-products.json --limit 120 --headed
```

Если Ашан отдает QRator-челлендж вместо каталога, сборщик завершится с ошибкой, а предыдущий `data/auchan-products.json` останется на месте.

## Как обновить данные Пятерочки

GitHub Pages не умеет парсить сайт магазина в момент клика. Поэтому данные Пятерочки обновляются отдельным локальным сборщиком, который записывает результат в `data/pyaterochka-products.json`.

Пошагово:

1. Откройте в обычном браузере сайт `https://5ka.ru/`.
2. Выберите город или адрес доставки, например Москва.
3. Установите Python 3.10+ или Python 3.12. Системный Python 3.9 для этого сборщика не подходит.
4. Установите зависимости:

```bash
python3.12 -m pip install -r requirements-scraper.txt
python3.12 -m camoufox fetch
```

5. Запустите сборщик:

```bash
python3.12 scripts/fetch_pyaterochka.py --limit 120
```

Если появится ошибка вроде `NS_ERROR_NET_RESET`, `403`, `VPN` или `Проблемы со связью`, значит сайт Пятерочки сбрасывает или блокирует соединение из текущей сети. В этом случае:

- откройте `https://5ka.ru/` в обычном браузере;
- проверьте, что каталог открывается без страницы блокировки;
- выберите город или адрес доставки;
- временно отключите VPN или попробуйте другую сеть;
- после этого запустите сборщик повторно.

6. После успешного запуска обновленный файл `data/pyaterochka-products.json` можно закоммитить и отправить в GitHub:

```bash
git add data/pyaterochka-products.json
git commit -m "Update Pyaterochka catalog data"
git push origin main
```

## Следующие шаги

1. Проверить сборщик Пятерочки на локальном Mac с выбранным городом или адресом.
2. Добавить отдельный слой `StoreProduct` и `PriceSnapshot`.
3. Перенести проект в React/Next.js, когда структура интерфейса будет утверждена.
4. После Пятерочки подключить Перекресток и Дикси по такой же схеме.
