# Gros.farm Price Monitor

Стартовая интерактивная болванка для сервиса мониторинга цен по одному выбранному магазину.

## Что уже есть

- выбор города и периода;
- выбор одной торговой сети: `Пятерочка`, `Перекресток`, `Дикси`;
- категории: `Фрукты`, `Овощи`, `Ягоды`, `Зелень`, `Грибы`;
- поиск по ассортименту выбранной сети;
- таблица товаров с текущими ценами;
- выбор нескольких товаров;
- SVG-график динамики цен по выбранным товарам.

## Как запустить сайт локально

Из папки проекта:

```bash
node server.js
```

Потом открыть:

```text
http://127.0.0.1:4173/
```

Сервер отдает статический интерфейс и локальные API для обновления кеша данных.

## Как обновляются данные Ашана

Интерфейс не парсит сайт Ашана напрямую из браузера. Он читает последний сохраненный кеш:

```text
data/auchan-products.json
```

При выборе Ашана список товаров берется из этого файла. Кнопка **Обновить** отправляет локальный запрос:

```text
POST /api/stores/auchan/refresh
```

Локальный сервер запускает сборщик:

```bash
python3 scripts/fetch_auchan.py --output data/auchan-products.json --limit 120
```

Если Ашан отдает QRator-челлендж вместо каталога, старый кеш не перезаписывается, а интерфейс показывает понятную ошибку и продолжает работать с последними сохраненными данными.

Также страница раз в 2 часа вызывает:

```text
POST /api/stores/auchan/refresh-if-stale
```

Этот endpoint обновляет данные только если файл кеша старше двух часов.

## Как обновить данные Пятерочки

GitHub Pages не умеет парсить сайт магазина в момент клика. Поэтому данные Пятерочки обновляются отдельным локальным сборщиком, который записывает результат в `data/pyaterochka-products.json`.

Пошагово:

1. Откройте в обычном браузере сайт `https://5ka.ru/`.
2. Выберите город или адрес доставки, например Москва.
3. Установите Python 3.10+ или Python 3.12. Системный Python 3.9 для этого сборщика не подходит.
4. Установите зависимости:

```bash
python3.12 -m pip install -r requirements-scraper.txt
python3.12 -m camoufox fetch
```

5. Запустите сборщик:

```bash
python3.12 scripts/fetch_pyaterochka.py --limit 120
```

Если появится ошибка вроде `NS_ERROR_NET_RESET`, `403`, `VPN` или `Проблемы со связью`, значит сайт Пятерочки сбрасывает или блокирует соединение из текущей сети. В этом случае:

- откройте `https://5ka.ru/` в обычном браузере;
- проверьте, что каталог открывается без страницы блокировки;
- выберите город или адрес доставки;
- временно отключите VPN или попробуйте другую сеть;
- после этого запустите сборщик повторно.

6. После успешного запуска обновленный файл `data/pyaterochka-products.json` можно закоммитить и отправить в GitHub:

```bash
git add data/pyaterochka-products.json
git commit -m "Update Pyaterochka catalog data"
git push origin main
```
